# Photo uploads

Drop project photos into the matching space folder:

- `uploads/bathrooms/`
- `uploads/kitchens/`
- `uploads/living-rooms/`
- `uploads/bedrooms/`
- `uploads/ellada.jpg`        — portrait (already set)
- `uploads/fleur-de-lis.jpg`  — logo (already set)

## Naming
Name files in the order you want them to appear, e.g. `01.jpg`, `02.jpg`, `03.jpg` …
(Any image extension works: .jpg / .jpeg / .png / .webp)

## Tips
- Keep each file roughly under ~2–3 MB so the site stays fast.
- Landscape and portrait orientations both work — the gallery is masonry.

After uploading, tell Claude "photos are pushed" and the galleries will be wired up.
